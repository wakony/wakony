# Wakony

Security researcher and developer. Building tools for supply chain integrity.

## Projects

**[CerberusWard](https://github.com/wakony/cerberusward)** — Zero-dependency supply chain integrity scanner for JS/TS projects. 13-phase detection engine, 56 IOC rules, binary analysis, SARIF output. Built from real-world incident response to nation-state attacks.

**[C2Monitor](https://github.com/wakony/C2Monitor)** — Real-time C2 beacon detection for Windows. Monitors DNS, network connections, and process behavior for blockchain C2, DGA domains, and hidden node processes.

**[Guardian](https://github.com/wakony/guardian)** (archived — succeeded by CerberusWard) — Original supply chain config scanner. All detection capabilities now in CerberusWard with 13 phases instead of 3.
